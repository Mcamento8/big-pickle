# تشغيل OmniRoute في وضع الإنتاج (النسخة السريعة والخفيفة)

## لماذا وضع التطوير بطيء؟

أداة OmniRoute المفتوحة المصدر تستخدم `npm run dev` — وهو وضع التطوير الذي:

- **يحمّل كل الكود في الذاكرة** (529 مكوّن + 104 صفحة) للتعديل السريع
- **يحتفظ بـ HMR** (Hot Module Replacement) للاستجابة الفورية عند تغيير الكود
- **يسمح بـ 8GB رام** (`--max-old-space-size=8192`) بسبب حجم الكود الأصلي
- **لا يُصغّر الكود** — ينقله كما هو للمتصفح

**النتيجة:** استهلاك 4-6GB رام + بطء في التنقل والاستجابة

## الحل: وضع الإنتاج

النسخة الجاهزة (المغلقة المصدر) التي تراها سريعة وخفيفة لأنها **بناء إنتاج** — نفس الأداة لكن مُصغّرة ومُجزّأة.

### خطوات التشغيل السريع

```bash
# 1. بناء الإنتاج (مرة واحدة — يأخذ 2-5 دقائق)
npm run build

# 2. تشغيل الإنتاج (خفيف وسريع)
npm run start
```

**النتيجة:** 
- استهلاك رام: **150-300MB** (بدلاً من 4-6GB)
- سرعة التنقل: **فورية** (بدلاً من بطيء)
- سرعة الاستجابة: **فورية** (بدلاً من تأخير)

### سكربت مدمج (بناء + تشغيل)

```bash
# بناء وتشغيل في سطر واحد
npm run start:prod
```

## مقارنة الوضعين

| الخاصية | وضع التطوير (`dev`) | وضع الإنتاج (`start`) |
|---------|-------------------|---------------------|
| استهلاك الرام | 4-6 GB | 150-300 MB |
| سرعة التنقل | بطيء | فوري |
| سرعة الأزرار | بطيء | فوري |
| التعديل المباشر | ✅ مدعوم | ❌ يتطلب إعادة بناء |
| الأخطاء المفصلة | ✅ مفصلة | ❌ مُصغّرة |

## متى تستخدم وضع التطوير؟

استخدم `npm run dev` فقط عندما:
- تريد **تعديل الكود** وتجربة التغييرات فوراً
- تعمل على **إصلاح خطأ** وتريد رؤية التفاصيل

## متى تستخدم وضع الإنتاج؟

استخدم `npm run start` عندما:
- تريد **استخدام الأداة** بدون تعديل الكود
- تريد **أفضل أداء** واستهلاك رام منخفض
- تعمل على **خادم إنتاجي** أو تستخدم الأداة يومياً

## نصائح للحفاظ على الأداء

### 1. لا تشغّل وضع التطوير لفترة طويلة
```bash
# ❌ خاطئ — وضع التطوير يستهلك الرام حتى لو لم تتعديل شيء
npm run dev

# ✅ صحيح — بناء الإنتاج مرة واحدة ثم تشغيله
npm run build
npm run start
```

### 2. أعد البناء بعد تغيير الكود
```bash
# إذا غيرت الكود وأعدت تشغيل dev، أعد البناء للإنتاج
npm run build
npm run start
```

### 3. استخدم السكربت المدمج
```bash
# بناء وتشغيل في سطر واحد
npm run start:prod
```

## استكشاف الأخطاء

### إذا كان الإنتاج بطيء أيضاً
```bash
# تحقق من إصدار Node.js (يجب أن يكون 22+)
node --version

# تحقق من بناء الإنتاج
npm run build

# راجع السجلات
npm run start 2>&1 | tee omniroute.log
```

### إذا ظهرت أخطاء بعد البناء
```bash
# أعد البناء من الصفر
rm -rf .build dist
npm run build
npm run start
```

### إذا كنت تريد تقليل رام الإنتاج أكثر
```bash
# في بعض الحالات النادرة، يمكنك تقليل heap size
NODE_OPTIONS="--max-old-space-size=512" npm run start
```

## ملخص

| الأمر | الوصف | الرام | السرعة |
|-------|-------|-------|--------|
| `npm run dev` | وضع التطوير | 4-6 GB | بطيء |
| `npm run build` | بناء الإنتاج | — | — |
| `npm run start` | تشغيل الإنتاج | 150-300 MB | سريع |
| `npm run start:prod` | بناء + تشغيل | 150-300 MB | سريع |

**القاعدة الذهبية:** إذا لم تكن تُعدّل الكود، لا تستخدم `npm run dev`.
